# 🍓 Pinku & Berri

My first ever game made with Godot! 🎮

Help Pinku collect all the strawberries and reach the trophy 🏆

## 🎮 Controls
- ⬅️ Left Arrow — Move left
- ➡️ Right Arrow — Move right
- Space + Arrow — Jump higher in that direction
- W/A/S/D — Don't work 😭

## 🍓 Goal
Collect all 15 strawberries and reach the trophy!

## 🛠️ What I learned
This game was honestly a LOT of debugging 😭
I struggled with collisions, TileMaps, collectibles, the counter, audio and exporting the game.

But somehow... **I MADE IT!** 🚀
